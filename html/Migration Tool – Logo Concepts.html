Migration Tool – logo concepts

Five directions for software that moves VMs, networks, edge gateways and the rest of a cloud estate from one place to another. Each one is built around a different idea of what “migration” looks like.

Migration Tool

1. Flock

Migratory birds as chevrons, each a different workload leaving the cloud: a VM, a network, a gateway. Reads as movement and direction without a literal arrow.

Migration Tool

2. Layers in transit

A stack of infrastructure layers (compute, network, edge) with the top one lifted off and sliding to its new home. Works well as a favicon and in a dense UI.

Migration Tool

3. Cube hop

A workload cube leaves a ghosted source cloud and lands in a solid destination cloud. The most literal option: the story of the product is clear in one second.

Migration Tool

4. Cloud m

A monogram: the two humps of the letter m double as the lobes of a cloud, with a data point travelling over them. Compact and ownable, and easy to put on a dark button or app icon.

Migration Tool

5. Node handoff

A network graph moving from a hollow dashed circle to a filled one. Speaks to networks, gateways and topology rather than just VMs, and suits a technical, infrastructure-first brand.
